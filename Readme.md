# Smart Clock App

Welcome to the **Smart Clock App**, a React-based application designed to provide a stylish and interactive clock interface with multiple timekeeping features. This project showcases a modular design with components for an alarm clock, stopwatch, timer, and theme toggling, enhanced with animations and user interaction.

## Project Overview

- **Developed By**: Sahil Jain
- **Technology Stack**:
  - React
  - Framer Motion (for animations)
  - Lucide React (for icons)
  - TypeScript (for type safety)

This app is a personal project to explore React component development, state management, and user interface animations. It includes a responsive design with a dark/light mode toggle and plans for future enhancements.

## Features

- **Alarm Clock**: Displays the current time with a customizable alarm feature, including a 3D clock face animation.
- **Stopwatch**: (Planned) A component to track elapsed time with lap functionality.
- **Timer**: (Planned) A countdown timer with adjustable duration.
- **Theme Toggle**: Switch between light and dark modes with a smooth transition.

## Installation

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/smart-clock-app.git
   cd smart-clock-app
   ```

2. **Install Dependencies: Ensure you have Node.js installed, then run:**
    ```bash 
    npm install
    ```


3. **Available Scripts:**
    - Start the development server:
      ```bash 
      npm start
      ```
    - Build the project for production:
      ```bash 
      npm run build
      ```
